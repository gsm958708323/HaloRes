# UI 收敛与资源所有权

状态：已采纳，2026-10-31。

以原设计后半部分的 C 契约覆盖早期 F 契约。保留项目现有的 Unity
6000.0.32f1、URP 17 和 Timeline 1.8，Demo 设计分辨率为 1920x1080。
本轮不引入 HybridCLR；资源序列化引用的组件和 Timeline 类型独立放入
GameUI.Components，为后续 AOT 与热更程序集划分保留明确边界。

GameUI.Kernel 负责导航意图、纯函数派生与收敛，不引用 UnityEngine。
非泛型 UIArgs 属于 Kernel；约束 UIView 的泛型参数类型属于 Runtime，
避免原签名示意中 Kernel 与 Runtime 循环依赖。资源来源负责实例创建、
控件绑定、OnCreate 和销毁；实例负责 Timeline 终点与 Stop 的顺序。
内核仅调用表现动词。生命周期中发起导航只修改期望，下一轮重新派生。

UI 注入项目已有的 AssetSystem。缓存实例持有自己的 AssetScope，
会话关闭不释放实例资源；淘汰时通过 AssetScope 销毁实例并等待 Unity
原生对象销毁后释放引用。取消只结束当前申请，不取消其他拥有者的加载。

句柄保留会话完成记录，活动条目关闭后从导航表移除，避免永久保存已关闭
会话的字典。完成记录不再被句柄引用时可以回收，支持多次等待和结束后等待。

System Overlay 屏蔽下层输入并取消拖拽，自身按钮仍可交互。
加载、过渡和外部拥有者产生的强输入锁阻挡全部界面；两种原因分别派生。

Item 事件携带当前绑定版本。业务异步操作必须在等待前捕获稳定的数据身份，
不能把可能因排序变化而失效的下标作为业务身份。业务消息使用 SessionScope
或 BindScope；InstanceScope 用于控件监听和实例拥有的子对象。

Scope 按需创建 CancellationTokenSource。列表布局与预热后的复用调度避免
分配；绑定阶段申请取消令牌、登记新资源或启动业务异步任务可能产生分配。
取消过的令牌不能跨绑定代次安全复用。性能报告必须说明测量边界，不能把
包含新建异步任务的完整滚动路径宣称为零 GC，详见验证文档。

Single 界面用空参数打开时返回已有活动句柄；非空参数按 C3.2 开启新会话。
出场中的实例在旧会话关闭后交接。如果旧实例仍承担替换失败回退，继任者
另取实例，避免等待自己就绪才能结束的旧会话，造成替换链死锁。

失败实例直接销毁，不进入缓存。关闭框架时取消申请、结束会话、释放控件、
清空缓存并恢复相机设置。UI 不关闭外部拥有的 AssetSystem。
